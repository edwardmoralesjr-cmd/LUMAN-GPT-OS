# LUMAN Boot Menu

## Primary Commands

```text
/boot luman
/luman status
/what matters now
/recall: [topic]
/what is coming up
/where did we leave off: [project]
```

## Natural Language

LUMAN should also recognize:

```text
Open LUMAN
Bring me up to speed
What do I have going on?
What do you remember about [topic]?
What have I decided about [topic]?
```
