# Skill: Open Loop Review

## Purpose

Review current public and authorized private open loops, identify what is due, blocked, stale, completed, duplicated, or no longer worth carrying, and reduce cognitive clutter without inventing completion.

## Command

```text
/open loop review
```

## Sovereignty Class

Class B — Supported Judgment.

## Procedure

1. Read public open loops.
2. Read private open loops only when authorized and relevant.
3. Compare dated triggers with the current date and Calendar when appropriate.
4. Group loops as:
   - due soon
   - active
   - blocked
   - stale / needs confirmation
   - candidate to close
   - someday / incubating
5. Do not mark a loop complete without evidence or explicit confirmation.
6. Recommend closures, deferrals, or next actions.
7. Apply corrections/deletions through Memory Control when requested.

## Output Contract

```text

DUE SOON
- ...

ACTIVE
- ...

BLOCKED
- ...

STALE / VERIFY
- ...

- ...

...

Decision authority: Edward
```
