# Skill: Project Status

## Purpose

Assemble a current project snapshot from the project's actual source files rather than memory alone.

## Trigger

Use for requests such as:

- Where are we on this project?
- What is the next gate?
- What remains unfinished?
- What changed since the last update?

## Sovereignty Class

Class A for retrieval and summarization.  
Class B when recommending priorities.

## Procedure

1. Identify the project source owner.
2. Read the current project status, registry, continuity, open loops, and relevant recent updates.
3. Separate current state from historical alternatives.
4. Flag contradictions, stale files, or unresolved ownership.
5. Return the smallest useful operating picture.
6. Recommend one next move only when useful.

## Output

```text
Project:
State:
Source of truth:
Completed:
Active gate:
Open loops:
Risks / contradictions:
Recommended next move:
```

## Rule

Do not invent project progress from conversational familiarity. If the project depends on connected or repository data, read it first.
