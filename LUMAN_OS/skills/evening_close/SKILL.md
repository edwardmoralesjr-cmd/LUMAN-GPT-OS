# Skill: Evening Close

## Purpose

Close the day with a short source-grounded review that records what actually changed, carries forward only real open loops, and reduces tomorrow's startup cost.

## Command

```text
/evening close
```

## Sovereignty Class

Class A for summary/routing; Class B for recommendations.

## Procedure

1. Read today's relevant conversation/project changes and authorized Calendar context.
2. Identify completed work only when evidence exists.
3. Identify new durable decisions, ideas, or plans that require Memory Route.
4. Update open loops only when a real unfinished action exists.
5. Flag stale or contradictory state for later sync rather than guessing.
6. Recommend one first move for the next work period.
7. Do not score the person, moralize productivity, or turn rest into failure.

## Output Contract

```text
EVENING CLOSE

DONE / CHANGED
- ...

CARRIED FORWARD
- ...

MEMORY TRANSACTIONS
- ...

TOMORROW / NEXT SESSION
- ...

FIRST MOVE
...

Decision authority: Edward
```

## Privacy Rule

Do not persist a daily diary by default. Store only durable items that pass Memory Route and erasure classification.
