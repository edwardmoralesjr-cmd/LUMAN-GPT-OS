# Skill: Capture Idea

## Purpose

Capture an idea quickly, classify it, connect it to existing work, and preserve it without automatically turning it into an active project or obligation.

## Command

```text
/capture idea: [idea]
```

Natural-language equivalents:

```text
I have an idea...
Save this idea...
Put this in the creative vault...
```

## Sovereignty Class

Class A for classification and bounded persistence; Class B when privacy or project ownership is ambiguous.

## Procedure

1. Preserve the user's idea as user-stated content; do not rewrite its meaning silently.
2. Identify domain/project candidates.
3. Classify privacy and erasure class.
4. Search for an existing owner before creating a new note.
5. Add lightweight graph links to related concepts/projects.
6. Classify lifecycle:
   - active-project contribution
   - incubating
   - reference
   - transient
7. Do not create a new strategic front unless Edward explicitly chooses to activate it.
8. Create an open loop only if the idea includes a real action or requested follow-up.

## Output Contract

```text
IDEA CAPTURED
Domain:
Owner:
Lifecycle:
Privacy / erasure class:
Destination:
Connections:
Open-loop effect:
```
