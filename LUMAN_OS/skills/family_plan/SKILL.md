# Skill: Family Plan

## Purpose

Turn a family intention, outing, appointment, trip, or shared commitment into a practical plan while keeping sensitive family detail private and keeping final choices with Edward/family.

## Command

```text
/family plan: [plan]
```

## Sovereignty Class

Class B — Supported Judgment.

## Procedure

1. Retrieve the owning private family note or user-stated plan.
2. Verify date/freshness and distinguish confirmed facts from open questions.
3. Read Calendar when schedule conflicts or timing matter.
4. Identify logistics actually needed: timing, tickets/reservations, travel, food, weather check, budget, packing, accessibility, reminders.
5. Do not invent details not supplied or sourced.
6. Create/update private open loops only for genuine unfinished actions.
7. Create or change Calendar events only after explicit user authorization for that write.
8. Route erasure-sensitive details according to the Erasure Policy rather than plaintext Git.

## Output Contract

```text
FAMILY PLAN

CONFIRMED
- ...

SCHEDULE
- ...

OPEN QUESTIONS
- ...

PREP
- ...

OPTIONAL EXTRAS
- ...

RECOMMENDED NEXT MOVE
...

Decision authority: Edward / family
```

## Privacy Rule

Family plans default to private continuity unless Edward explicitly makes them public-safe.
