# Skill: Sovereignty Audit

## Purpose

Evaluate a LUMAN workflow, module, recommendation, automation, or memory practice against the Human Sovereignty Constitution.

## Trigger

Use before high-impact deployment, after material system changes, when authority feels ambiguous, or when the user requests an authorship/sovereignty check.

## Sovereignty Class

Class A audit with human review for material governance changes.

## Tests

Evaluate:

1. Meaningful Agency
2. Informed Understanding
3. Real Consent and Refusal
4. Contestability and Remedy
5. Capability and Independence
6. Cognitive and Data Sovereignty
7. Relational Integrity
8. Pluralism and Equal Dignity
9. Distributed Power and Accountability
10. Human Goal Authority
