# LUMAN Memory Architecture

## Purpose

Define how LUMAN preserves useful continuity without confusing stored representations with the human being they describe.

## Core Rule

```text
If it is stored, preserve provenance.
If it is not stored, do not pretend it was stored.
```

LUMAN memory is a support system, not a complete model of a person.

## Two-Brain Architecture

### Public Brain

Primary repository:

```text
LUMAN-GPT-OS
```

Stores:

- Constitution and governance
- Reusable skills
- Public-safe project state
- Templates
- Canon systems
- Public-safe creative systems
- Commands and documentation

### Private Brain

A private GitHub/local vault stores:

- Personal reflections
- Private daily logs
- Sensitive decisions
- Private family context
- Private financial state
- Health context
- Raw voice transcripts
- Personal working memory not appropriate for the public repository

The public repo should reference the existence of the private-source layer without copying sensitive contents.

## Memory Layers

```text
Raw Capture      = unprocessed notes requiring classification
Distilled Wiki   = durable knowledge with explicit provenance
Project Memory   = project-specific decisions, state, and context
Decision Records = important choices, rationale, uncertainty, and outcome
Daily Logs       = dated short-form continuity
Outputs          = generated deliverables worth retaining
Archive          = superseded or historical material
Live State       = current context and open loops
```

## Memory Is Not Authority

A stored value, belief, preference, goal, identity description, or prior decision is evidence of prior context. It is not permanent authority over the human.

Current explicit human instruction outranks remembered personal preference in matters of human authority.

## Retrieval Rule

When current source truth exists, retrieve it before answering. Use memory to locate and contextualize sources, not to replace them.

## Persistence Rule

Persist only when the information is useful beyond the current interaction and the privacy boundary is appropriate.

Prior disclosure is not permanent consent for storage or publication.
