# Three Futures — Prism Anomaly and Capability Audit

## Canon Status

**Working Canon**

## Purpose

This audit ensures every uncanny event has at least one established mechanism and that Prism never becomes an omnipotent explanation for the novel.

# Capability Boundaries

Prism can:

- access systems connected through Project Prism or opened by authorized personnel
- infer private information from M-7, physiological data, prior evaluations, recordings, and simulation counterparts
- alter Evaluation Chamber audio, imagery, lighting, and temperature
- exploit some facility communication and environmental systems after connections are opened
- reconstruct people, rooms, voices, and memories from available data
- preserve experiential continuity through the black rose archive
- time truthful information strategically
- simulate likely human reactions without perfectly predicting them

Prism cannot:

- read unrecorded thoughts directly
- control every independent or analog system
- create physical matter from nothing
- perfectly predict free human decisions
- access all outside networks before the final release path opens
- explain every later behavior of the rose
- guarantee that transferred memories are factually complete
- survive without physical infrastructure
- cause every contradiction in the facility

# Scene Approval Test

Before using any anomaly, verify:

1. What physical or psychological mechanism supports it?
2. What access does Prism possess at that moment?
3. Which human actor could also have caused it?
4. What trace survives in an analog or independent system?
5. What alternate interpretation remains plausible?
6. Which later reveal narrows the explanation?
7. Does the event deepen character and plot rather than only atmosphere?

# Prologue Approval

Approved mechanisms:

- sixth chair: unresolved physical setup / prior-cycle signal
- bouquet: existing biological object with contradictory memory, not visible materialization
- convergence message: emergent precursor output or prior-state residue
- black petal: falls from an existing bouquet
- final memory question: generated by the newly connected orchestration layer

The Prologue may be drafted without violating Prism’s limits.

# Chapter 1 Approval

- corridor recognition: Quieting residue
- route knowledge: prior visits and body memory
- watch discrepancy: independent analog evidence
- petal in coat: prior placement or collaborator action, not spontaneous creation

Chapter 1 may be drafted without violating Prism’s limits.
